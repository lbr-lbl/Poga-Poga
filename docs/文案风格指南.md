# Poga Poga 文案风格指南

> 依据当前 UI 的实际文案整理（Poga、拿下！、可惜、时间暂停、继续吧、再来！、不玩啦、选择地图、对手性格……）。
> 以后新增或修改 UI 文案都按这份语气来，不要再写“系统/玩家个体/进行”这类机翻腔。

## 一句话原则

**短、直接、像人在说话；输了不骂人，赢了不客套。**

## 1. 称呼

- 玩家操控的史莱姆叫 **Poga**（首字母大写），不要叫“玩家”“角色”“本体”“玩家个体”。
- 对手按性格称呼：**善良 / 和平 / 邪恶**；不要写“AI 难度 0/1/2”。
- 其他史莱姆可以直接叫“对手”或“它们”。

## 2. 语气

- 按钮用 2~5 个字：`继续吧`、`再来！`、`不玩啦`、`拿下！`、`可惜`、`选择地图`。
- 允许短感叹句和打气句，但不要每句都感叹：
  - `越挫越勇，Poga想当第一名`
  - `时间暂停`
- 失败、失误不责备玩家，不写“您失败了”“操作错误”。
- 不用客服腔：`请点击`、`是否要`、`系统将`、`开始您的`。

## 3. 句式

- 一句话只放一个信息，先说动作/结果，再说条件。
- 少用括号；只有按键说明可以放括号。
- 能省的字就省：
  - “比赛会自动暂停，回来后从当前帧继续。” → **“时间暂停”**
  - “耐力清空会进入喘息，之后才慢慢恢复” → **“喘口气，耐力会回来”**
  - “目标：第一名冲线；失败按 R 重试。” → **“第一名冲线，输了按 R 再来”**
- 数字只在需要精确比较时出现（时间、经验、排名）；不要用数字讲机制。

## 4. 常用词替换

| 不这么写 | 这么写 |
| --- | --- |
| 玩家个体 / 角色 / 本体 | Poga |
| 对手强度 / AI 难度 | 对手性格 |
| 进行比赛 / 开始您的比赛 | 出发 / 再来一局 |
| 是否继续 | 继续吧 / 不玩啦 |
| 已累积经验 | 经验 |
| 重置车手等级（清空等级/经验/加点） | 重开一局？（需要二次确认） |
| 系统提示 / 警告 | 小提示 |

## 5. 文案长度

- 主菜单按钮：≤ 5 字（`开始游戏` 可以，`车手 · 加点` 已改成 `Poga`）。
- 暂停菜单按钮：≤ 4 字。
- 情境提示：≤ 22 字，一行说完。
- 结算数据行：左边是项目名，右边是数值；不要写成长句。
- 帮助页说明：每条 ≤ 30 字，一条一个操作。

## 6. 当前 UI 里的正例

- `时间暂停` / `继续吧` / `再来！` / `不玩啦`
- `拿下！` / `可惜` / `越挫越勇，Poga想当第一名`
- `选择地图` / `点击地图立即出发`
- `对手性格：善良 / 和平 / 邪恶`
- `需要操作指引：开 / 关`

## 7. 自检清单

- [ ] 玩家史莱姆是否写成 Poga？
- [ ] 按钮是否 ≤ 5 字，且像人话？
- [ ] 有没有“系统/玩家个体/进行/是否/请”这类词？
- [ ] 一句话里是不是塞了两个以上信息？
- [ ] 失败/低耐力相关文案是否在责备玩家？
- [ ] 数字是否只用在真正需要比较的地方？
- [ ] 和当前 UI 的短句、口语语气是否一致？
