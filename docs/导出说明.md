# 导出说明（v0.191）

## 产物

| 平台 | 路径 | 说明 |
| --- | --- | --- |
| Windows x86_64 | `build/windows/PogaPoga.exe` | 单文件 exe，已内嵌 pck，带 Poga 图标 |
| Android 通用 | `build/android/PogaPoga.apk` | debug 签名；arm64-v8a + armeabi-v7a + x86_64，可直接安装测试 |

## 图标

- `icon.png`：512×512 主图标（Poga 史莱姆）
- `icon_192.png` / `icon_432.png`：Android 启动图标
- `icon.ico`：Windows exe 图标

## 导出配置

- `export_presets.cfg`：
  - `Windows Desktop`：x86_64、内嵌 pck、`res://icon.ico`
  - `Android`：arm64-v8a、包名 `com.pogapoga.game`、debug 签名、启动图标 `icon_192/icon_432`
- 项目已开启 `rendering/textures/vram_compression/import_etc2_astc=true`（Android 纹理压缩要求）。

## 重新导出

```powershell
$godot = 'D:\下载\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe'
& $godot --headless --path . --export-release 'Windows Desktop' 'build/windows/PogaPoga.exe'
& $godot --headless --path . --export-debug 'Android' 'build/android/PogaPoga.apk'
```

- 导出模板：`H:\C-backup\Godot-export_templates\4.7.2.stable`（Godot 4.7.2.stable）。
- Android SDK：`C:\Users\Administrator\AppData\Local\Android`；Java：`H:\Openjdk`。
- 当前 APK 为 **debug 签名**，用于安装测试；正式上架需要自行配置 release keystore 后改用 `--export-release 'Android'`。
- Android 使用 **GL Compatibility** 渲染器、`viewport` 拉伸（内部 1280×720），以降低平板高分屏的填充压力；Mumu（x86_64）已实测安装启动。
- 如果平板仍有抽帧：优先在设备设置里把游戏加入性能/高帧率白名单，或降低屏幕刷新率；还可以把 `display/window/stretch/mode` 保持 `viewport`，不要改回 `canvas_items`。
